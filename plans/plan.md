# Plan - Execution Order

This is the order for the three feature plans.
Use this order to keep feedback fast.

## 1. Crawl

Read `plans/plan-crawl.md`.
Build the document files.
**Checkpoint**: one good `.md` file for each source page.

## 2. Ingest

Read `plans/plan-ingest.md`.
Build the vector index.
**Checkpoint**: the app returns a real answer from the knowledge base.

## 3. WebLLM

Read `plans/plan-webllm.md`.
Run inference in the browser.
**Checkpoint**: the app answers without an API key.

## Pause

Stop after step 3.
Reassess the state of the app.
Change the plan only after review.
